## 🗂 미션 - 로또 자판기 기능 목록 (재정렬)

### 1️⃣ 사용자 입력
- [x] 사용자의 로또 구입금액을 입력받는다
    - [x] ⚠️ 숫자가 아닌 입력을 했는지 확인
    - [x] ⚠️ 1000원으로 나누어 떨어지는지 확인
- [x] 당첨 번호를 입력받는다
    - [x] ⚠️ 중복된 번호로 입력했는지 확인
    - [x] ⚠️ 쉼표로 구분했는지 확인
    - [x] ⚠️ 6개의 숫자를 입력했는지 확인
    - [x] ⚠️ 1부터 45까지의 숫자를 입력했는지 확인
- [x] 보너스 번호를 입력받는다
    - [x] ⚠️ 보너스 번호가 1부터 45까지 사이의 수인지 확인
    - [x] ⚠️ 보너스 번호가 당첨번호와 겹치는지 확인

### 2️⃣ 로또 구매 및 추첨
- [x] "n개를 구매했습니다." 라는 문구 출력
- [x] n번만큼 로또를 추첨
- [x] 구매된 로또를 출력
    - [x] 로또번호를 오름차순으로 정렬한다

### 3️⃣ 당첨 결과 계산
- [x] 당첨 내역을 출력한다
    - [x] 몇 개만큼 당첨번호가 일치하는지 판단
    - [x] 당첨된 금액을 합산

### 4️⃣ 수익률 계산 및 출력
- [ ] 수익률을 보여준다
    - [ ] 당첨금액을 구입금액으로 나눈 뒤 100을 곱한다
    - [ ] 소수점 둘째 자리에서 반올림한다 (소수 첫째 자리까지만 보여줌)

### ☑️ 체크리스트
- [ ] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
- [ ] 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- [ ] 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- [ ] else 예약어를 쓰지 않는다.
- [ ] Java Enum을 적용하여 프로그램을 구현한다.
- [ ] 구현한 기능에 대한 단위 테스트를 작성한다. 단, UI(System.out, System.in, Scanner) 로직은 제외한다.
- [ ] camp.nextstep.edu.missionutils에서 제공하는 Randoms 및 Console API를 사용하여 구현해야 한다.
- [ ] Random 값 추출은 camp.nextstep.edu.missionutils.Randoms의 pickUniqueNumbersInRange()를 활용한다.
- [ ] 사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.
